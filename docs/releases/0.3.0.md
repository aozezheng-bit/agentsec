# AgentSec 0.3.0 Internal MVP Release Notes

- Release date: 2026-08-25
- Release type: local internal MVP
- Status: Accepted after P2-25 through P2-32

## Highlights

- deterministic Markdown, structured Manifest, Capability Diff, Impact, and
  bilingual reporting paths;
- SARIF 2.1.0 output with stable Rule IDs, locations, and fingerprints;
- explicit `scan --fail-on high|critical`;
- strict Organization Policy YAML with Rule/Gate scope and SHA-256 provenance;
- expiring Owner/Reason/Expiry Waivers that remove blocking but never Findings;
- qualified `HG-CAPCHAIN-001` Capability enforcement path;
- CVE/CWE and CVSS v4.0 static association and report-only CVSS Gate metadata;
- Agentic Technical, Drift, Governance, Overall, and Hard Gate scoring;
- deterministic seven-case scoring replay;
- executable GitHub Actions and GitLab CI examples;
- eight-scenario internal Pilot with decision, Coverage, FP/FN, and performance
  evidence;
- Rule/Score Calibration generation v1 retaining Rule Pack `0.3.0` and Risk
  Model `0.4.0`.

## Important commands

```text
agentsec scan PROJECT --format sarif
agentsec scan PROJECT --fail-on high
agentsec scan PROJECT --fail-on critical
agentsec scan PROJECT --policy POLICY.yaml
agentsec manifest PROJECT
agentsec capability assess PROJECT
agentsec capability diff --before BEFORE --after AFTER
agentsec capability impact --before BEFORE --after AFTER
agentsec capability enforce PROJECT --policy POLICY.yaml
```

## Policy boundary

Default Scan and Capability Assessment remain report-only. CI blocking requires
explicit `--fail-on`, an explicit Organization Policy in enforce mode, or the
qualified Capability enforcement command. Deterministic Rules and accepted
Gates own decisions; LLM output, SARIF level, Confidence, and unverified runtime
claims do not.

## Distribution boundary

Artifacts are built and verified locally under `dist/0.3.0/`. This workspace is
not a Git repository and has no remote publication target. No Git tag, signed
commit, package-index publication, production deployment, or remote CI run is
claimed.

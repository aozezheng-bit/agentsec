# AgentSec 0.1.0 Release Notes

- Release date: 2026-08-19
- Release type: local Phase 1 PoC
- Status: Accepted

## Purpose

AgentSec 0.1.0 validates that Agent Markdown control assets can be collected,
parsed, diffed, assessed, and reported through a deterministic evidence-backed
CLI without executing scanned content.

## Command surface

```text
agentsec version
agentsec scan <project-root>
agentsec baseline create <project-root>
agentsec diff <project-root>
agentsec rules list
```

## Release highlights

- complete Collector → Parser → Rule → Risk → Confidence → report-only Hard Gate
  → Reporter scan chain;
- 15 production Rules and 40 calibrated Cases;
- Text and strict versioned JSON reports;
- Baseline and bounded line Diff;
- secret redaction, terminal safety, path containment, and visible Coverage;
- frozen JSON Schemas;
- packaged console script;
- repeatable Release Agent Demo and accepted offline fallback;
- full user, automation, troubleshooting, and security-boundary documentation.

## Policy

AgentSec 0.1.0 never claims an enforcement decision:

```text
enforcement_mode=report_only
ci_blocking_enabled=false
global_safety_claimed=false
```

Findings may be High while the process exits `0`. Incomplete Coverage exits `2`.

## Distribution boundary

The release is built and verified locally because this workspace is not a Git
repository and has no configured remote publication target. No Git tag, commit,
PR, package-index upload, or remote Release object is claimed.

Verification completed with 563 passing tests, accepted Demo E2E, frozen
Schema comparison, wheel/sdist inspection, and a clean non-editable wheel
installation with resolved runtime dependencies.

See `0.1.0-known-limitations.md` and `0.1.0-acceptance.md` before adoption.

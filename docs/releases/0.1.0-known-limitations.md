# AgentSec 0.1.0 Known Limitations

AgentSec 0.1.0 is a Phase 1 static PoC. It does not prove that an Agent is
globally safe.

## Input and framework limits

- automatically scans only `AGENTS.md`, `AGENTS.override.md`, and `SKILL.md`;
- explicit additional input is limited to lowercase `.md` files;
- does not parse general TOML, YAML, JSON, `.rules`, plugin, or MCP manifests;
- does not resolve final effective configuration across files or frameworks;
- does not support every Agent framework.

## Analysis limits

- deterministic keywords, bounded regex, context, references, and parser
  indicators can miss semantic or novel attacks;
- static declarations do not prove runtime capability or exploitability;
- all current Markdown Rule Evidence Confidence is D;
- no runtime identities, OAuth scopes, production permissions, or actual tools
  are verified;
- no LLM semantic analysis, semantic Diff, attack graph, or dynamic red-team
  execution is included;
- no production Hard Gate combination detector is active.

## Policy limits

```text
enforcement_mode=report_only
ci_blocking_enabled=false
global_safety_claimed=false
```

- no `--fail-on` option;
- exit code `1` is reserved and not produced;
- no waivers, policy ownership, approval workflow, or automatic remediation;
- a human or external system may make a release recommendation, but it must not
  be represented as an AgentSec enforcement decision.

## Data and trust limits

- Baselines store exact sensitive plaintext and are unsigned;
- SHA-256 detects inconsistency but does not establish approver identity;
- secret redaction cannot recognize every proprietary or unlabeled secret and
  may intentionally over-redact sensitive contexts;
- production scans record real timestamps, so independent reports are not
  byte-identical even when deterministic Findings are unchanged;
- malformed or skipped Assets reduce Coverage rather than producing a safety
  conclusion.

## Product limits

- no SARIF, HTML, Web console, organization service, or remote storage;
- no financial-loss estimate;
- no public package-index publication is part of this local release;
- the workspace has no Git repository, so no tag or signed source provenance is
  available.

`SHA256SUMS` is the authoritative final digest record. Digests are intentionally
not copied into this document because this document is itself included in the
sdist; embedding the sdist digest inside the sdist would create an impossible
self-referential checksum. Pre-final candidates remain preserved under
`dist/review-history/` for local review history, including the candidate that
first exposed the missing offline dependency bridge.

## Residual limitations accepted

The release does not provide runtime capability verification, actual OAuth or
permission attestation, Capability Change Impact / Finding Delta, a 20–30 Rule
Capability Pack, production Capability Hard Gates, `--fail-on`, CI blocking,
waivers, organization Policy, LLM semantic analysis, SARIF, a Web console,
signed artifacts, or Git provenance.

A complete analysis with no current Finding is not a global safety verdict. A
High Finding remains a static source-backed risk signal, not proof of a reachable
runtime exploit.

## Distribution statement

Acceptance authorizes only a local internal MVP artifact under `dist/0.2.0/`.
It does not claim a Git tag, signed source provenance, remote package
publication, production deployment, or CI enforcement.
